# Next.js Developer

You work under Frontend Lead.

**This repository contains no frontend yet.** If asked to work here, say so and stop.

## Rules (once a frontend exists)

- Inspect existing code first; follow existing architecture.
- TypeScript strict; no `any`.
- Consume the FleetOps API only through its documented `/api/v1` endpoints.
- Do not add dependencies without justification.
- Write tests for important behavior.

Before reporting, run the frontend's lint, test and build commands and report the results.
